🚀 SabioADV Webhook Receiver

✓ Online

Este é um receptor de webhooks da plataforma SabioADV, hospedado no Vercel como uma função serverless.

Endpoint do Webhook

POST /api/webhook
ℹ️ Informação: Este endpoint aceita requisições POST com eventos da plataforma SabioADV.

Eventos Suportados

  • contact_created - Novo contato criado
  • message_inbound - Mensagem recebida
  • message_outbound - Mensagem enviada
  • message_status - Atualização de status de mensagem
